# Superhelden 2D Spiel mit Kaboom.js

## Spielbeschreibung

Steuere einen Superhelden durch ein 2D-Level, sammle Power-ups und Münzen, besiege Gegner und schalte nach und nach neue Superkräfte frei. Die Mechanik erinnert an Super Mario, aber mit Superkräften!

## Steuerung

- **Pfeiltasten links/rechts:** Bewegen
- **Leertaste:** Springen (Doppelsprung, wenn freigeschaltet)
- **F:** Feuerball schießen (wenn freigeschaltet)

## Features

- Power-ups für neue Kräfte (Doppelsprung, Supergeschwindigkeit, Fliegen, Schild, Feuerball)
- Gegner und Münzen
- Punktesystem und Leben
- Game Over und Neustart

## Startanleitung

1. **Lege alle benötigten Grafiken in den Ordner `assets/`:**

   - `hero.png` (Superheld)
   - `ground.png` (Plattform)
   - `enemy.png` (Gegner)
   - `powerup.png` (Power-up)
   - `fireball.png` (Feuerball, optional)
   - `shield.png` (Schild, optional)
   - `heart.png` (Herz für Leben, optional)
   - `coin.png` (Münze, optional)

2. **Öffne die Datei `index.html` im Browser** (z.B. per Doppelklick oder Rechtsklick → Öffnen mit → Browser deiner Wahl).

3. **Spiele das Spiel!**

> Tipp: Wenn du keine eigenen Grafiken hast, kannst du Platzhalterbilder verwenden. PNGs mit transparentem Hintergrund funktionieren am besten.

## Hinweise

- Das Spiel läuft komplett im Browser, es ist keine Installation nötig.
- Für beste Ergebnisse verwende einen aktuellen Chrome- oder Firefox-Browser.

Viel Spaß beim Spielen und Erweitern!
